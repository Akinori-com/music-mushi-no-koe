## 使い方

### 1ページ目：がっきを えらぶ
1. 昆虫カードをタップして鳴き声を聴く
2. 鳴き声に合う楽器をドラッグまたはタップで昆虫の下に置く
3. 「**えんそうへ すすむ ➡️**」ボタンを押して演奏画面へ！

### 2ページ目：えんそうしよう！
1. 「**▶️ さいせい**」ボタンを押すと曲がスタート
2. 歌詞画像と合わせて、画面右側に「**いま ならす がっき**（1ページ目で選んだ楽器）」が表示されて光ります！
3. 「**🐢 ゆっくり(0.8) / 🚶 ふつう(1.0) / 🐇 はやい(1.2)**」でテンポを変更可能
4. 「**⬅️ がっきを えらぶ**」でいつでも1ページ目に戻って楽器を選び直せます

## 画像・音声ファイルの準備

- 画像形式: PNG または JPG
- 音声形式: MP3
- 画像がない場合でも自動で代替テキストやプレースホルダーが表示されます

---

## 演奏の切り替えタイミングを変更したい場合

`index.html` 内の `songTimeline` 配列にある `startTime` / `endTime` の秒数を変更することで、歌詞画像や楽器の切り替えタイミングを微調整できます。
